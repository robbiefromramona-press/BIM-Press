BIM-Press Revit Shortcut Manager v1

Open index.html in Edge or Chrome. No installation or internet connection is required. The page embeds the supplied Revit 2023, 2024, 2025, and 2026 XML files and also includes those originals alongside it.

Choose a version or import your team's Revit shortcuts XML. Search a command, type one or more shortcuts separated by #, commas, or semicolons, then Apply. Red rows identify duplicate assignments; yellow rows identify edits. Export Revit XML to download the edited profile. Export Change List CSV creates a change summary. The imported original remains available through Restore Imported Original or Download Original Backup.

Use Poster Generator, then Print / Save Poster PDF and select Save as PDF in the browser print dialog. Poster output includes currently assigned shortcuts grouped by ribbon category and may span multiple landscape pages.

In Revit, open Keyboard Shortcuts (KS), choose Import, select the exported XML, and confirm. Back up the current profile first. The app changes only the Shortcuts attribute for edited records and keeps other command records and attributes from the imported XML. All file processing happens locally in the browser.

Limits: duplicate assignment checks are made within the loaded XML. Reserved-key rules are not guessed. The supplied XML contains add-in entries that may not exist on coworkers' machines. Version compatibility is not guaranteed when importing a profile from a different Revit release. This is a practical portable HTML v1, not an Excel workbook or Autodesk product.
