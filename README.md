# BIM-Press

The BIM-Press website: free BIM and layout apps, games and training for the people who build.

**Live:** https://bim-press.com

The site lives in `WEBSITE/` and is plain static HTML, deployed on Netlify. It also hosts the Revit Keys shortcut manager at `WEBSITE/apps/revit-keys/`.

Built with Claude by robbiefromramona-press.
